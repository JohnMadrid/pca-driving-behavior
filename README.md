# PCA Driving Behavior

This repository contains the notebook workflow for PCA-based driving behavior analysis and downstream interpretation.

## OSF Project Structure

Data and notebooks are organized in separate OSF components:

- **Data component**: raw and derived datasets required to run the analysis
- **Code component**: analysis notebooks and project code in this repository

OSF DOI:

- [https://doi.org/10.17605/OSF.IO/B4XKN](https://doi.org/10.17605/OSF.IO/B4XKN)

Expected core data files:

- Raw data (folder: `raw/`)
  - `EEDA_autonomous_raw_unitvectors.csv`
  - `EEDA_manual_raw_unitvectors.csv`
- Cleaned data
  - `EEDA_cleaned.csv` (unzip `EEDA_cleaned.csv.zip`)
- Questionnaire data
  - `EEDA_Qdata.csv`

## Main Notebook Workflow

Run notebooks in this order:

- `0_preprocessing.ipynb`
- `1_demographics.ipynb`
- `2_pca.ipynb`
- `3_variance_analysis.ipynb`
- `4_ed.ipynb`
- `5_discriminant_analysis.ipynb`

## Expected Data Files

### Raw data

Place raw CSV files in `raw/`:

- `raw/EEDA_autonomous_raw_unitvectors.csv`
- `raw/EEDA_manual_raw_unitvectors.csv`

### Derived and questionnaire data

- `data/EEDA_cleaned.csv` (generated by `0_preprocessing.ipynb`)
- `data/EEDA_Qdata.csv` (questionnaire data)

## Notebook Inputs and Outputs (Quick Map)

- `0_preprocessing.ipynb`
  - **Input**: raw unit-vector CSVs in `raw/` (or `data/raw/` fallback if configured)
  - **Output**: `data/EEDA_cleaned.csv` and cleaning artifacts under `results/data_cleaning/`
- `1_demographics.ipynb`
  - **Input**: `data/EEDA_cleaned.csv`, `data/EEDA_Qdata.csv`
  - **Output**: merged demographics summaries by condition
- `2_pca.ipynb`
  - **Input**: `data/EEDA_cleaned.csv`
  - **Output**: PCA artifacts under `results/` (`cleaned_new/`, `variances/`, `components/`, `eigenvalues/`, `biplots/`, `cos_plots/`)
- `3_variance_analysis.ipynb`
  - **Input**: variance outputs from `results/variances/all_events/`
  - **Output**: variance summaries and visualizations
- `4_ed.ipynb`
  - **Input**: eigenvalue outputs from `results/eigenvalues/all_events/`
  - **Output**: effective dimensionality summaries and visualizations
- `5_discriminant_analysis.ipynb`
  - **Input**: cleaned PCA outputs from `results/cleaned_new/all_events/`
  - **Output**: time-resolved discriminant metrics and visualizations under `results/pc-interp/`

## Minimal Setup

1. Create and activate a Python environment.
2. Install dependencies:
  - `pip install -r requirements.txt`
3. Run notebooks from the project root directory.

## Reproducibility Notes

- Keep the project folder structure unchanged after downloading from OSF.
- Computations in `0_preprocessing.ipynb` take long, thus a cleaned dataset is provided
